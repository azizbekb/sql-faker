# SQL Faker — fake user generator (Task 6)

All fake data is generated by **PostgreSQL stored procedures** (`db/`). The Python/Flask
app (`app/`) only calls `fk_users(locale, seed, batch)` and renders HTML.

* Locales: English (USA) `en_US`, German (Germany) `de_DE`. More can be added with data only.
* Name, address, uniform-on-sphere geolocation, normal-distributed height/weight/age,
  eye/hair colour, blood type, phone, e-mail, Markov-chain "about" text.
* Deterministic: same locale + seed + position → same user.
* ~2 000 complete users / second per CPU core (see `docs/benchmark.txt`).

**Documentation of the stored procedures: [docs/README.md](docs/README.md)**
(also served by the app at `/docs`).

## Run locally

```bash
createdb faker && scripts/init_db.sh faker
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
DATABASE_URL="dbname=faker" .venv/bin/flask --app app/app.py run     # http://localhost:5000
```

or with Docker: `docker compose up --build` → http://localhost:8000

## Deploy (Render, free tier)

Push the repo to GitHub → render.com → **New → Blueprint** → select the repo.
`render.yaml` creates the PostgreSQL database and the web service; `INIT_DB=1` loads the
SQL library on start.
